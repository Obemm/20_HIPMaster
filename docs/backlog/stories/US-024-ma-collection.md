# US-024 — Ma collection

- **Epic** : EPIC-03
- **Statut** : À affiner
- **Priorité** : Must
- **Taille** : M
- **Branche** : `us-024-ma-collection`

## Récit

En tant que **joueur connecté**, je veux **voir les cartes que je possède et celles qui me manquent** afin de
**suivre ma progression dans le set**.

## Critères d'acceptation

- [ ] La page collection affiche la **progression du set** (ex. « 37 / 71 ») et, par rareté, le nombre de cartes
      obtenues.
- [ ] Chaque carte possédée montre son nombre d'exemplaires (doubles) ; les cartes manquantes restent visibles,
      grisées, avec leur nom, pour donner envie.
- [ ] Les filtres du catalogue (famille, rareté) s'appliquent, plus un filtre « possédées / manquantes ».
- [ ] Le détail d'une carte (US-009) indique le nombre d'exemplaires possédés.
- [ ] Tests de l'API et de l'écran ; parcours e2e et audit axe-core au vert.
