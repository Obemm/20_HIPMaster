# EPIC-05 — Card illustrations

- **Status**: Done
- **Priority**: Should

## Goal

Give every card a quality illustration, in a style that is consistent across the whole set.

## Success indicator

All the cards of the first set have an optimised illustration (WebP/AVIF, under 100 KB) and an alternative text.

## Stories

- [x] US-009 — Playing-card style card design
- [x] US-015 — Illustration import and optimisation pipeline
- [x] US-016 — Art direction and choice of the image generator
- [x] US-017 — Illustrations for the 71 cards of set 1
- [x] US-018 — Provisional illustrations generated by code
- [x] US-078 — Fingerprinted illustrations, cached for a year

Order: US-015 depends on nothing and comes first; US-016 waits for the project owner's decision on the tool
([Recraft](https://www.recraft.ai) on a paid plan, or another route); US-017 follows both.

## Out of scope

Animated cards, holographic effects (to be considered later); uploading the images to Azure (at go-live, ADR 0008).
