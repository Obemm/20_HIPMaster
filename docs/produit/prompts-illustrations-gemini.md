# Prompts d'illustration pour Gemini — set 1

Prompts générés à partir du catalogue (`packages/domain/src/set-1.ts`) et de la
[direction artistique](direction-artistique.md). Un prompt par carte, en anglais (la langue que les générateurs suivent
le mieux), avec le bloc de style commun déjà inclus.

Mode d'emploi :

1. Générer d'abord une carte, et garder l'image préférée comme **référence de style**.
2. Pour les suivantes, joindre cette image avec : _Use the attached image as the style reference: same line, same
   lighting, same background treatment._ Pour une **évolution**, joindre aussi l'image de sa carte d'origine.
3. Déposer chaque image en PNG 4:3 (au moins 1365 × 1024) dans `packages/illustrations/sources/set-1/<numéro>.png`,
   puis lancer `npm run illustrations`.
4. Retoucher le sujet d'une carte si l'image ne convient pas : seule la première phrase du prompt change.
